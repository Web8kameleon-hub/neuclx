# NeuCLX

NeuCLX is the clean, sovereign AI synthesis repository for the Web8kameleon-hub profile.

## Non-negotiable truth contract

NeuCLX never fills an evidence gap with an artificial result. Every value carries one explicit epistemic state:

- `measured`
- `computed`
- `declared`
- `unavailable`
- `not_implemented`

The only mandatory policy boundary is the JONA sandbox.

## Bootstrap status

This commit initializes the repository. Runtime code, architecture records, provenance, tests, and source-repository mappings are developed through reviewed branches and pull requests.

## Dependency policy

The core runtime and its tests use the language standard library only. External LLMs, model weights, hosted inference services, and hidden fallback generators are outside the core.
