# Candidate quarantine

Files here are immutable candidate snapshots, not NeuCLX runtime modules. A copied candidate must come from a public source and match the repository revision, blob SHA, and SHA-256 recorded in manifest.json.

Private repositories are represented by metadata references only. Rejected and unavailable sources remain recorded so the 16-repository audit has no invented gaps.

Promotion requires a NeuCLX-native adaptation, tests, benchmark evidence, provenance update, dependency review, and JONA approval. Candidate files are never imported by the runtime.
