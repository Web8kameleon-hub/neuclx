# HVO Memory - Neurosonic's Six Memory Types

> **Constitutional grounding:** MR001-MR006 Memory Rules, G009 Knowledge Law.

## What is HVO Memory?

HVO is an abbreviation for **Horizontal, Vertical, Orbital** - the three core
dimensions along which Neurosonic stores knowledge. It is the memory layer of the
AI operating system, defined in `neurosonic_dna.py`.

## The six memory types

Neurosonic defines six memory rules (MR001-MR006):

| ID | Memory | Purpose |
|----|--------|---------|
| MR001 | **HVO Memory** | Horizontal, Vertical, Orbital dimensions. |
| MR002 | **Resonance Memory** | Weighted by importance / relevance. |
| MR003 | **Film Memory** | Stores the history of a process. |
| MR004 | **Stigma Memory** | Learns from experience (sensitivity to past results). |
| MR005 | **Working Memory** | Current task context (short-lived, active). |
| MR006 | **Long Term Memory** | Permanent knowledge storage. |

## Understanding the three axes (HVO)

- **Horizontal (H)** - *Breadth* of knowledge: wide coverage across topics and
  connections between entities.
- **Vertical (V)** - *Depth* of understanding: layered detail within a single
  topic.
- **Orbital (O)** - *Time-based context and relationships*: how knowledge is
  positioned over time and relative to other knowledge.

## How memory supports truth

Because every fact in Neurosonic is expected to have a **source** and a **hash**
(Shtylla 2 of the constitution), the memory layer stores provenance alongside
content. This makes the Knowledge Graph (G009) a single, versioned source of
truth rather than a loose collection of claims.
